# FocusFlow — Week 1 Static Webpage

## Files
- `index.html` — semantic HTML page
- `style.css` — styling and responsive layouts
- `script.js` — mobile navigation toggle
- `Week1_Design_Report.docx` — design and implementation report

## How to run
1. Keep all files in the same folder.
2. Open `index.html` in a modern web browser.
3. Resize the browser or use developer tools to check tablet and mobile layouts.

The page uses Google Fonts when an internet connection is available. It still has fallback fonts if the fonts cannot load.
