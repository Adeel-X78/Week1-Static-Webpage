
# FocusFlow – Responsive Static Website

## Project Overview
FocusFlow is a modern and responsive productivity landing page developed using HTML, CSS, and JavaScript.

The website is designed to present a simple productivity platform that helps users organise their daily tasks, manage priorities, and improve their daily routine.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Website Sections
The website includes the following sections:

1. Navigation Bar
2. Hero Section
3. Features Section
4. How It Works Section
5. Quote Section
6. Call-to-Action Section
7. Footer

## Main Features
- Clean and modern user interface
- Responsive layout for desktop, tablet, and mobile devices
- Semantic HTML structure
- CSS Grid and Flexbox layouts
- Mobile navigation menu
- Simple JavaScript functionality
- Consistent colours, typography, and spacing

## Project Files
- index.html – Main webpage structure
- style.css – Website styling and responsive design
- script.js – Mobile navigation functionality
- REPORT.md – Design and development report

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the index.html file.
4. Double-click index.html to open the website in your browser.

## Responsive Design
CSS media queries are used to adjust the layout for different screen sizes, including desktop, tablet, and mobile devices.

## Project Purpose
This project was developed as part of Week 1 internship training to practise HTML structure, CSS styling, responsive web design, and basic JavaScript functionality.
